# Milestone: Order Processing System

This milestone manages the complete lifecycle of customer orders, including checkout, payment verification, and fulfillment dispatch.

## Slice: Checkout Processing

- [ ] Validate shopping cart inventory
- [ ] Calculate sales tax and shipping fees
- [ ] Create order record in database

## Slice: Payment Settlement

- [ ] Authorize charge via payment gateway
- [ ] Send invoice email to customer
- [ ] Update payment status in database

## Slice: Fulfillment Routing

- [ ] Reserve items in warehouse database
- [ ] Generate shipping label
- [ ] Notify shipping carrier
